# 🚀 Roadmap проекта: Система оценки вовлеченности студентов (Engagement Detection)

## 📌 ФАЗА 1 — Исследование и прототип (Недели 1–2)

---

## ✅ Неделя 1 — Формализация задачи

### 🎯 Цель недели

Понять, что именно мы измеряем, и спроектировать основу системы.

### Что нужно сделать:

* Четко определить понятие **“вовлеченность”**

  * признаки: взгляд в экран, поза, активность, отсутствие сна/отвлечения

* Выбрать архитектуру проекта (**модульная структура**)

* Принять ключевые решения:

  * будет ли использоваться **gaze estimation**?
  * будет ли использоваться **body pose estimation**?

* Найти и выбрать 2–3 датасета:

  * DAiSEE (engagement)
  * EmotiW Engagement dataset
  * Classroom behavior datasets (если найдешь)

* Сделать архитектурную схему pipeline

### 📌 Результат недели:

✅ Документ с архитектурой
✅ Список технологий и датасетов
✅ Четкое понимание метрики “engagement”

---

## ✅ Неделя 2 — Базовая детекция (первый вау-эффект)

### 🎯 Цель недели

Запустить real-time прототип: камера → лицо → угол головы.

### Реализовать:

* Детекция лиц:

  * MediaPipe Face Detection
  * или YOLOv8-face

* Отрисовка bounding box

* Получение head pose:

  * yaw / pitch / roll

* Вывод углов на экран в реальном времени

### 📌 Результат недели:

🎥 Камера видит лицо и показывает направление головы
➡️ Первый рабочий “wow prototype”

# 📅 ФАЗА 2 — Фичи и данные (Недели 3–5)

---

## ✅ Неделя 3 — Feature Extraction

### 🎯 Цель недели

Собрать числовые признаки поведения ученика.

### Добавить фичи:

* Head Pose (yaw/pitch)
* Eye Aspect Ratio (моргание)
* Направление взгляда (упрощённо)
* Наклон корпуса (если успеваешь)

### Собрать feature vector:

Пример:

```
[x_yaw, x_pitch, blink_rate, gaze_dir, body_tilt]
```

### 📌 Результат недели:

Для каждого ученика → набор чисел, готовых для ML.

---

## ✅ Неделя 4 — Сбор данных (самая важная неделя)

### 🎯 Цель недели

Создать свой датасет под задачу.

### Сделать:

* Записать видео с учениками (с разрешением)
* Разметить кадры на классы:

  * engaged
  * not engaged

### Формат разметки:

```csv
frame_id, student_id, label
0001, 1, engaged
0002, 1, not_engaged
```

### Минимальная цель:

📌 1000–3000 размеченных примеров

### 📌 Результат недели:

Собственный dataset → основа всей модели.

---

## ✅ Неделя 5 — Первая ML-модель

### 🎯 Цель недели

Получить первые реальные метрики.

### Сделать:

* Разделить данные train/test

* Обучить baseline модели:

  * Logistic Regression
  * Random Forest

* Сравнить результаты

* Вывести метрики:

  * Accuracy
  * Precision / Recall
  * F1-score

### 📌 Результат недели:

Первая настоящая модель engagement classification.

# 📅 ФАЗА 3 — Улучшение качества (Недели 6–8)

---

## ✅ Неделя 6 — Temporal анализ (ключевой апгрейд)

### 🎯 Цель недели

Добавить понимание поведения во времени.

### Вместо одного кадра:

* Sliding window (например 5 секунд)
* Усреднение предсказаний
* Temporal smoothing

### Почему важно?

Это резко уменьшает шум и улучшает качество.

### 📌 Результат недели:

Модель перестает “дергаться” и становится стабильной.

---

## ✅ Неделя 7 — Улучшение модели
